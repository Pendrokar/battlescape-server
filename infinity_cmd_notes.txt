IB command line arguments:

-server = Launch a Infinity Battlescape dedicated server
-serverconfig <xml> = Server configuration XML file
-shared = Unknown; Server privately shared?
-private = Unknown; Server accessable only with correct IP, token or password?
-public = Unknown; Server viewable in server browser?
-offline = Client only
-reboot = Unknown; Do not load DB?
-mission <xml> = Server-only. Mission XML file run by the dedicated server. Irrelevant to client login/auth.
-steam = Tells the Game that it is launched from Steam (User check when clicking Multiplayer)
-launcher = Configure the game launcher
-direct <ip> = Adds that IP to the multiplayer server browser list only. Does not automatically connect.
-join = Boolean parsed by the exe; Client immediately attempts to connect to the server specified with -direct argument
-spawn = Boolean parsed by the exe; purpose unknown
-auth <?token> = Server-browser listing/join token for official/public servers. Not used by local dedicated servers.
-offline = Sets local login name to "default". Does not auto-connect to a running dedicated server.
-port <port> = Server port (127.0.0.1)
-portrange <num> = Port range (default 5)
-host <ip> = Server IP (7778)
-serverpassword <password> = Admin password?
-dedicated = Dedicated server
-username <name>
-instance
-entrypoint <string> = changes the value of the global variable `Global.EntryPoint` to use in Mission Scripts
-nopreload = Client skips caching assets from ActorList.xml and loads them only on demand
