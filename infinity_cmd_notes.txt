IB command line arguments:

-server = Launch a Infinity Battlescape dedicated server
-serverconfig <xml> = Server configuration XML file
-shared = Server privately shared?
-private = Server accessable only with correct IP, token or password?
-public = Server viewable in server browser?
-offline
-reboot = Do not load DB?
-mission <xml> = Mission XML file
-steam = Tells the Game that it is launched from Steam (User check when clicking Multiplayer)
-launcher = Configure the game launcher
-direct <ip> = Server browser IP or direct server (does not by itself join)
-join = Actually join/connect to the -direct/-host server (without this the client sits in the main menu)
-spawn = Skip to spawn menu after connect?
-auth <?token> = Parameter required by server browser (Steam related); without this: host IP does not get recognized, cannot ping servers; seems to skip Steam API
-port <port> = Server port (127.0.0.1)
-portrange <num> = Port range (default 5)
-host <ip> = Server IP (7778)
-serverpassword <password> = Admin password?
-dedicated = Dedicated server
-username <name>
-instance
-entrypoint
